# Security Policy

## Supported Versions

Security reports are accepted for the latest release of this fork.

## Reporting a Vulnerability

Please report vulnerabilities in this fork privately via
[GitHub Security Advisories](https://github.com/Bastii717/FlashPaper/security/advisories/new).
We will strive to respond within a few days.

For issues in the original upstream project, see
[AndrewPaglusch/FlashPaper](https://github.com/AndrewPaglusch/FlashPaper/blob/master/SECURITY.md).

Thank you!
