# FlashPaper expiry fix + UI rework (variant B "console") Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Enforce secret expiry on retrieval (Part A, own branch), then restyle every page of the fork to the "Dark Ops, neutral" console design with honest copy (Part B, stacked on A).

**Architecture:** Server-rendered PHP templates stay; Bootstrap and `color-toggle.js` are replaced by one self-hosted stylesheet (`css/flashpaper.css`), one script (`js/flashpaper.js`) and a self-hosted Fira Code woff2. Small view helpers live in `includes/ui.php` so header/footer work even when the sanity check renders them without `$settings`. Not-found and too-long become dedicated exception subclasses so `index.php` can route them to their own views without changing exception texts or the JSON API.

**Tech Stack:** PHP 8.4 (alpine php84, no mbstring), nginx, SQLite via PDO, vanilla JS, CSS custom properties.

**Spec:** `docs/superpowers/specs/2026-11-19-ui-rework-design.md` (visual reference `mockups/b.html` + `mock.css`, uncommitted, never shipped).

## Owner decisions already made (2026-11-19)

- Expiry fix goes **first**, as its own branch/commit (Part A). The UI keeps the hard tile wording "Unopened secrets are removed after N–M days".
- Docker builds and smoke tests run on a separate Docker host (`DOCKER_HOST=ssh://<docker-host>`), not the workstation. Browser checks go through an SSH port-forward.
- Nothing is pushed, no PR, no tag without explicit OK.

## Owner decisions requested with this plan (defaults in bold, used unless overruled)

1. **`docker-compose.yml`**: it hard-codes every old `MESSAGES_*` string, so anyone copying it keeps the old copy. Default: **remove the `MESSAGES_*` lines from the example** (comment points to the README), keep the other env lines.
2. **README**: the `prune` and `display_logo` sections go stale. Default: **update those two sections** in Part B. "zero-knowledge" intro wording and the screenshot stay separate follow-ups (not in this plan).
3. **Fira Code OFL licence**: the text must come from the upstream repo. Default: **download `https://raw.githubusercontent.com/tonsky/FiraCode/master/LICENSE` (~4 KB, SIL OFL 1.1) to `fonts/OFL.txt`**; needs your yes because it is a download.
4. **Theme migration**: upstream's script writes `localStorage.themePreference` on *first visit* (the system theme at that moment), not only on a toggle. Migrating it as the spec says pins every returning visitor to that theme and they stop following the system preference. Default: **migrate as the spec says** (old key → `fp-theme`, old key removed).
5. **Smoke tests**: the repo has no test framework. Default: **curl smoke script lives in the session scratchpad, not in the repo**.

- No external requests: no CDN, no remote font, no remote icon. Fonts as real files under `fonts/` (CSP has no `font-src`; `data:` fonts are blocked).
- Green-only accent; no red/amber/blue. "Danger" = inverted text/bg.

## Review Focus

1. **Pruning disabled** (`PRUNE_ENABLED=false`): an old secret past its `prune_epoch` must stay readable, as the README promises. → Task A1 test `expired_readable_when_prune_disabled`.
2. **JSON too-long**: the JSON branch has no try/catch; making too-long render inline must not change the API's response for an over-long secret. → Task B3 test `json_toolong_matches_baseline`.
3. **Multibyte secrets**: 300 × "ä" (600 bytes) at `MAX_SECRET_LENGTH=600` must pass, 301 must render the inline too-long message with the text refilled. → Task B3 tests `umlaut_600_bytes_ok`, `umlaut_602_bytes_toolong`.
4. **Secret starting with a newline / containing HTML**: `<pre>` swallows one leading newline, and the secret must be escaped exactly once. → Task B5 tests `reveal_escapes_once`, `reveal_keeps_leading_newline`.
5. **Sanity-check page with `$settings` unset**: must render the new error look with zero PHP warnings in the php-fpm log. → Task B2 test `sanity_page_no_warnings`.

- `$SP/build.sh <ref|worktree> <tag>`: `ref` → `git archive <ref> | DOCKER_HOST=ssh://<docker-host> docker build -t fp:<tag> -f docker/Dockerfile --build-arg FLASHPAPER_COMMIT=<sha> -`; `worktree` → `docker build . …` (only after B1's `.dockerignore` commit). Then prints `docker run --rm --entrypoint ls fp:<tag> /var/www/html`.
- `$SP/run.sh <tag> <name> <port> [extra -e …]`: `docker rm -f <name>; docker run -d --name <name> -p 127.0.0.1:<port>:80 -e BASE_URL=http://localhost:<port> -e MAX_SECRET_LENGTH=600 -e PRUNE_MIN_DAYS=7 -e PRUNE_MAX_DAYS=14 … fp:<tag>`, waits for "FlashPaper is ready." in `docker logs`.
- Port-forward: `ssh -N -L 18080:127.0.0.1:18080 -L 18081:127.0.0.1:18081 -L 18082:127.0.0.1:18082 <docker-host>` (background). Ports: 18080 main, 18081 legacy env, 18082 expiry/prune tests.
- `$SP/smoke.sh <base> <container>`: bash, `curl -s`, one function per named test below, prints `PASS name` / `FAIL name: <detail>`, exit 1 on any fail. Helpers: `mk <secret>` (JSON create → k), `expire <container> <id>` (in-container `php84 -r` PDO `UPDATE secrets SET prune_epoch = time()-60 WHERE id=…`, cwd `/var/www/html`), `rows <container>` (count rows), `phplog <container>` (`cat /var/log/php84/error.log`).
